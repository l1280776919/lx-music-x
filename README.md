# LX Music X 🎵

> 基于 **Tauri 2.0 (Rust) + Vue 3.5 + Vite 8 + TypeScript + UnoCSS** 重构的新一代高颜值、现代化跨平台音乐播放助手。

---

## ✨ 核心特性

- ⚡ **极致轻量**：告别 Electron 臃肿资源占用，常驻内存仅 ~40MB，安装包仅十几兆，随开随用。
- 🎨 **现代化 Apple Music 风格视觉**：封面自适应高斯模糊流光大屏、匀速自转黑胶唱片质感、拟态玻璃质感组件。
- 🔍 **全平台聚合音源与在线检索**：深度适配网易云、酷狗、QQ音乐、酷我、咪咕五大主流音源及自定义源。
- 💻 **本地音乐极速扫描**：基于 Rust 底层多线程极速遍历本地磁盘音频文件，原生无损解码直出。
- 🎛️ **10-Band 专业硬件 EQ 调音台**：Web Audio 原生 BiquadFilter 频段调节，内置摇滚、人声、重低音等调音预设。
- 🪟 **原生桌面悬浮歌词**：独立透明置顶窗口，毫秒级逐行对齐高亮，支持动态鼠标穿透。
- 📦 **旧版数据无缝兼容**：自动识别本机原版 `lx-music-desktop` 历史数据库 (`lx.data.db`)，一键无损导入自建歌单与收藏。

## 🛠️ 本地开发与构建

### 1. 安装依赖
```bash
pnpm install
```

### 2. 运行纯前端界面 (Web 预览)
```bash
pnpm dev
```

### 3. 运行 Tauri 桌面端 (含托盘、桌面歌词与原生能力)
```bash
pnpm tauri dev
```

### 4. 生产打包全量安装程序
```bash
pnpm tauri build
```

## 🚀 自动发布流程 (GitHub Actions)

本项目配置了自动化发布流水线：
- **分支推送 (master / main)**：不会触发打包，保证日常提交干净整洁。
- **Tag 推送 (`v*`)**：自动跨平台编译（Windows / macOS / Linux）并自动发布 GitHub Releases。
